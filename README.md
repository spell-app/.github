# spell-app/.github

The page you see at [github.com/spell-app](https://github.com/spell-app) lives here, in
[profile/README.md](profile/README.md).
GitHub shows that file on the organization's front page;  nothing else in this repo is public-facing.

Looking for Spell itself?  Start at [spell](https://github.com/spell-app/spell):
its README sets it up from zero and indexes every other README.

## What's here

| File | What it is |
| --- | --- |
| [profile/README.md](profile/README.md) | the organization's front page:  Spell in one screen, spaces, the one repo and its folders, where to go next |
| [profile/images/repos.svg](profile/images/repos.svg) | the folders of the one repo and what each uses;  a copy of its [docs/images/repos.svg](https://github.com/spell-app/spell/blob/main/docs/images/repos.svg) |
| [profile/images/languages-and-targets.svg](profile/images/languages-and-targets.svg) | human languages in, programming languages out;  a copy of [images/languages-and-targets.svg](https://github.com/spell-app/spell/blob/main/images/languages-and-targets.svg) |

## Changing the front page

- Edit [profile/README.md](profile/README.md);  GitHub shows the new text as soon as it's on `main`.
- The pictures are COPIES:  when the original in spell-app/spell changes, copy it over here too.
  A profile page can't show a picture from another repo by a relative path.
- Write it as the repos' READMEs are written:  "Spell" with a capital S in prose, nothing claimed that doesn't run,
  and what's coming marked 🌱.
- It names one repo, spell-app/spell, and its folders.
