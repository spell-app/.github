# spell-app/.github

The page you see at [github.com/spell-app](https://github.com/spell-app) lives here, in
[profile/README.md](profile/README.md).
GitHub shows that file on the organization's front page;  nothing else in this repo is public-facing.

Looking for Spell itself?  Start at [spell-kit](https://github.com/spell-app/spell-kit):
its README sets up all five repos from zero and indexes every other README.

## Changing the front page

- Edit [profile/README.md](profile/README.md);  GitHub shows the new text as soon as it's on `main`.
- The pictures are COPIES:  when the kit's or spell-lang's original changes, copy it over here too.
  A profile page can't show a picture from another repo by a relative path.
- Write it as the repos' READMEs are written:  "Spell" with a capital S in prose, nothing claimed that doesn't run,
  and what's coming marked 🌱.
- It names the five public repos only:  the kit, spell-lang, spell-ui, spell-epic and spell-app.
